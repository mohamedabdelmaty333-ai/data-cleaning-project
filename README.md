# مشروع تنظيف بيانات المبيعات

المشكلة

وجود بيانات غير منظمة في ملف CSV، مثل الأسماء الفارغة والمسافات الزائدة والقيم المكررة.

الحل

استخدام Python ومكتبة Pandas لتنظيف البيانات، وترتيب الأسماء، ومعالجة قيم المبيعات الفارغة، وحذف الصفوف المكررة.

النتيجة المتوقعة

إنشاء ملف جديد باسم "clean.csv" يحتوي على بيانات أكثر تنظيمًا وجاهزة للتحليل.

الأدوات المستخدمة

- Python
- Pandas
- CSV
